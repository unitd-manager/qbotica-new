### 🚀 Getting Started

**Backend (WordPress):**
```bash
cd backend
# WordPress runs on http://localhost
```

**Frontend (Next.js):**
```bash
cd frontend
npm install
npm run dev
# Runs on http://localhost:3000
```

### ⚙️ Project Info
- **Frontend Framework:** Next.js
- **Backend CMS:** WordPress
